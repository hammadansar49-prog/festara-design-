Questions

Asked at every family dinner.

Do guests need to download an app?

No. The invite opens in the phone's browser, the same way a WhatsApp link does.

Can my phuppo change the date by mistake?

Only Admins can edit an event. Members help plan, Guests only see the date and place.

Can one wedding have separate pages for each function?

Yes. Make Dholki, Mehndi, Baraat and Walima as separate events, each with its own link and people.

What happens when the invite link is old?

Links expire after seven days. An Admin can make a new one in a tap.
