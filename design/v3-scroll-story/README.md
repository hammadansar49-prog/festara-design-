# Festara v3: scroll-story prototype

Hammad's design prototype for the Festara home page. Live version: https://claude.ai/artifact/Beu6UK8w2cu3WyzzjzCWWE

- Three event worlds side by side (Weddings, University, Tours). Scrolling down moves the page sideways between them.
- Each world's "Start planning" opens its own themed planner form, ending in a share screen.
- Smooth scroll with Lenis, animation with GSAP ScrollTrigger (both loaded from CDN).

Open `index.html` in a browser to view it. Photos in `img/` are from Unsplash (free licence).
